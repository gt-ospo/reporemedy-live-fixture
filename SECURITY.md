# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using the process below.
Do not disclose sensitive details in public issues or pull requests.

Use GitHub's private vulnerability reporting: open the repository's Security tab
and choose "Report a vulnerability". If that is unavailable, email
security@example.org. We aim to acknowledge reports within 3 business days and
to share a fix or mitigation plan within 30 days.

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| 1.x     | Security fixes only, until 2026-12-31 |
| < 1.0   | No        |
